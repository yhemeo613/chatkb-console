# 微信高情商回复手册 · 职场篇

## 一、接住领导的表扬

错误姿势：过度谦虚（"没有没有，运气而已"——等于否定领导眼光）或过度表功。
正确公式：感谢 + 归功协作 + 轻描淡写带过自己。

- 谢谢领导！这次主要是测试同学把边界都兜住了，我把流程理顺了。
- 谢谢老板认可，团队配合给力，我继续加油。

扩展：领导私下表扬可以多说一句进度；群里表扬回复要短，不抢戏、不 @ 无关的人。

## 二、接领导安排的任务

先应下 + 确认关键信息 + 给时间点，不当场吐槽难度。

- 收到，这个我周三前先出一版方案给您看。
- 好的领导，我先确认下 X 的口径，明上午给您初稿。

如果手头确实排满：说明现状 + 给优先级选项，而不是直接说做不完。
- 领导，我手上还有 A 和 B 两件事在赶，这个新任务如果要周四交，A 需要顺延一天，您看优先级怎么排？

## 三、婉拒同事的求助

三明治法：先共情/肯定 → 明确拒绝 + 一个理由 → 给替代方案。
理由只给一个，不叠加。

- 周四周五我都在封闭改 bug，实在腾不出手。下周一你再来找我，我帮你看看。
- 这个我确实不熟，怕给你带偏。你可以问问 X，他上次做过类似的。

对方反复求：重复原拒绝即可，不加新理由，语气放缓。

## 四、催同事/下属给结果

给对方台阶 + 明确 deadline + 说明影响，不带情绪。

- X，那个数据我这边的截至时间是明早十点，麻烦今天下班前给我一版，有困难提前说。

## 五、向领导汇报坏消息

先说结论 + 已采取的动作 + 需要的支持，不隐瞒、不甩锅。

- 领导，X 项目接口今天联调发现不兼容，我们定位到是版本问题，已联系对方升级，预计明天中午恢复。如果影响上线时间，我晚上八点前同步您备选方案。

## 六、回领导深夜消息

克制、不表功、不表忠，直接回应事项本身。

- 收到，明早我一上班先处理这个，有结论同步您。

## 七、错发消息 / 工作失误被点名

认得快、补救实、不辩解。

- 抱歉，是我核对疏漏了。已把正确版本补发，另外在流程里加了双人核对，不会再出现。

## 八、同事甩锅时的公开回应

只摆事实时间线，不对人定性，给领导留裁决空间。

- 补充一下时间线：X 日上午我把接口文档发在了群里，X 日下午有过一次变更，我这边没收到同步。可能中间信息断掉了。

## 九、群里被 @ 但和你无关

简短回应防止刷屏，指向真正该回应的人。

- 这个 X 更清楚，@X 麻烦你看下。

## 十、离职/交接期的告别消息

感谢 + 留联系方式 + 祝福，不吐槽、不煽情过长。

- 感谢各位这几年的照顾，以后不在一个工位但还在一个行业，微信常联系。祝大家一切顺利。
