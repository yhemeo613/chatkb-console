# 微信高情商回复手册 · 社交与家庭篇

## 一、回应长辈的关心

顺着说 + 给细节 + 主动给行动承诺，不争论观点。

- 知道啦妈，这周末我回家吃饭，你想吃啥我提前买回去。
- 放心吧叔，我秋裤已经穿上了，您和婶也注意保暖。

长辈转发养生文：不纠错，接住关心。
- 好嘞，我存下来看看，您平时也多注意休息。

## 二、答应/婉拒亲友邀约

能去：爽快答应 + 确认时间地点 + 加一点主动性。
- 周六中午可以！老地方见？我带瓶酒。

不能去：感谢 + 简短理由 + 改期提议。理由只给一个。
- 哎这周六我恰好值班，下周我约你，咱们好好聚。

## 三、拒绝借钱（最难的场景）

原则：不当场答应也不翻脸；只拖延、给小额上限或明确不行；写微信留痕比口头好。

亲戚开口借大额：
- 哥，你这事我不该问，手头的情况实话说也紧，大额真拿不出来。我先给你转两千应急，别的你再看别处周转下？

朋友借钱不还又来借：
- 上次那笔你先缓缓没关系，这次真不巧我也刚交了一笔大的，实在挤不出来，你问问别人呢。

## 四、安慰与倾听

先接情绪，禁止"至少你还……"句式，给陪伴而不是建议清单。

- 这确实挺让人心累的……想吐槽随时找我，我都在。
- 别硬扛，晚上要不要出来走走？我陪你。

对方倾诉工作委屈：只听不站队，不跟着骂人。
- 听着确实憋屈，换我我也难受。后来呢？

## 五、道歉

认具体的事 + 已做的补救 + 以后怎么办，不说"但是"。

- 今天开会我那话说重了，对不起。事后我想了，其实你有你的考虑，是我急了。

## 六、催回复 / 追问进展

轻推 + 给出口，不质问。

- 忙完没？之前那事有个更新的版本不急，你看到了回我一声就行。

## 七、收红包 / 收礼物

即时感谢 + 具体说用途/心意，不空泛。

- 收到啦！谢谢姑妈，我用它买你上次说的那家点心，回头拍照给你看。

## 八、打破冷场 / 重新开启对话

给对方一个具体、低回答成本的话题，别问"在吗"。

- 刚路过你上次说的那家店，排队排到街尾，你们学校那边有这么夸张吗？
- 看到你朋友圈那张照片，是在 X 拍的吗？我也想去。

## 九、被夸奖（朋友场景）

大方接受 + 回敬一个具体的夸，不否认。

- 哈哈被你发现了，最近确实练了。你那个摄影才是真进步神速，改天教教我。

## 十、约人被放鸽子

先确认是否出了状况，表达损失但不攻击，给下次机会。

- 今天白等了呀，是不是临时有事的？下次定了时间你提前跟我说一声，我好改安排。
